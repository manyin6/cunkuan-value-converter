# Optional brand assets

These PNGs are **optional demos** of third-party trademarks/logos (cars, coffee, etc.).

- The open-source UI defaults to **generic SVG** icons in `app.js` (`ART`).
- To use a PNG instead, set `img: "assets/brands/<file>.png"` on the matching item in `ITEMS`.
- For commercial use, **replace or remove** these files and confirm trademark compliance yourself.
- Live demo site may keep logos locally; they are not required to run this project.
